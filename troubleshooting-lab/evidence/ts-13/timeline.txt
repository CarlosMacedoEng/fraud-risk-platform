== ANALYSIS (written after the run)
Observed live effect was SMALL: DECLINE 0.3% -> 0.4%, REVIEW 1.0% -> 0.5%. The k6 lab pool is dominated by
low-risk transactions, so it does not reproduce the offline evaluation finding (183 false declines for 1.0.0 vs 0
for 1.1.0 on the labelled evaluation set).
Confound: the SAME config (1.1.0) produced REVIEW 1.0% before and 5.3% after the rollback. Different transactions
and accumulated velocity state in each window -> before/after comparisons across time windows are unreliable.
Controlled comparison = the paired simulation (same 5,000 recent transactions scored by both versions):
decline 0.12% -> 0.34% (2.8x), review 5.62% -> 0.84%, 235 REVIEW->APPROVE and 11 ->DECLINE transitions.
Lesson: gate promotions on paired simulation / canary cohorts measured in the same window, not on before/after.
